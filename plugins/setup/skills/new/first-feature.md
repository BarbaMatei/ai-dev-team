# First feature

You propose where building starts; the owner picks; specsmd plans and builds it.

1. From the purpose, the users and the one thing they must do, write two or three candidate first features. Each: a short name, one sentence on what a user can do once it exists, and why it is a good start.
2. Recommend one: the smallest slice that runs end to end through every part (for example one page that saves to the API and reads back) and moves the must-do forward. Login or payments come first only when the must-do is exactly that.
3. One message: the candidates as a short list, your recommendation marked, ending "Which one?".
4. On the owner's pick, start specsmd inception with it: `/specsmd-inception-agent intent-create`, the feature's name and sentence as the intent. If that command is not available in this session yet, tell the owner to open a new session and run it with that line. The setup ends here.
